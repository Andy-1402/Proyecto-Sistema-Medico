## Descripción

Sistema Médico desarrollado con **Python** y **Django**, orientado a la gestión de una clínica o consultorio médico. Permite administrar pacientes, atenciones médicas, pagos y la seguridad de los usuarios del sistema.

## Módulos

- **Core:** gestión de pacientes y datos base del sistema.
- **Attention:** registro y seguimiento de las atenciones médicas.
- **Pagos:** control de los pagos realizados por los pacientes.
- **Security:** usuarios, roles y permisos de acceso.

## Tecnologías

- Python
- Django
- Celery (tareas programadas)
- GitHub Actions (integración continua)
